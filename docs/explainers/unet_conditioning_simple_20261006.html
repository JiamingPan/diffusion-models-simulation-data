Where the cosmology enters the UNet

A step-by-step guide to our conditional diffusion model, for readers who know tensors and math but are new to deep learning. Each section adds one idea. Intuition comes first, then the equation. The full math is in the Show the math boxes.

Conventions used on this page
  • One map is a tensor with shape \((C, H, W)\). \(C\) is the number of channels (Section 2). \(H = W\) is the size in pixels: 128, 64 or 32.
  • In training, the network sees a batch of \(B = 32\) maps at once: \((B, C, H, W)\). This page shows one map, so \(B\) is left out.
  • Three models are compared: baseline, temb and tembss. Colors in diagrams: orange = the cosmology enters here; green = only the noise level enters here.

1. The problem

A diffusion model makes a new map by removing noise, step by step. It starts from pure noise and runs the network 50 times. Each run removes a little noise. The network is a function with three inputs and one output:

  • the noisy map \(x_t\), shape \((1, 128, 128)\);
  • the noise level \(t\), an integer from 0 (clean) to 499 (pure noise);
  • the requested cosmology: \(\Omega_m\) (matter density) and \(\sigma_8\) (clustering amplitude).

The output is \(\hat v\), shape \((1, 128, 128)\). It tells which part of \(x_t\) is noise and which part is signal (the exact definition is in Section 9).

The final map must look like a universe with the requested \(\Omega_m\) and \(\sigma_8\). So these two numbers must change what the network does. The question of this page is: where and how do the two cosmology numbers get into the network? We have three answers. They are the three models baseline, temb and tembss. Section 4 compares them.

2. The UNet in one picture

The network is a UNet. The name comes from its U shape. It shrinks the map twice, then grows it back twice. Each size is one level. Data flows from the top left, down the left side, across the bottom, and up the right side.

down path up path middle skip connection
  1. Down path (left). At each level, 2 ResBlocks process the features (Section 3). Then a learned layer halves the height and width: 128 → 64 → 32.
  2. Middle (bottom). At 32×32: ResBlock, attention, ResBlock (Section 7).
  3. Up path (right). A layer doubles the height and width: 32 → 64 → 128. At each level, 3 ResBlocks process the features.
  4. Skips (dashed). The up path also gets a copy of the down-path features at the same level (Section 8).

Count of ResBlocks: 6 down + 2 middle + 9 up = 17, in every model.

What is a channel?

The input map has 1 channel: one number per pixel. The first layer, conv_in, turns it into 32 channels. A tensor with \(C\) channels is a stack of \(C\) images, all of size \(H\times W\). Each image is the output of one learned detector. For example, channel 1 might respond to sharp edges, and channel 7 to bright blobs. The network chooses these detectors during training. Nobody designs them by hand.

Worked example. At the 128×128 level, \(C = 32\). The tensor is \((32, 128, 128)\): \(32 \times 16\,384 = 524\,288\) numbers for one map. At the 32×32 level, \(C = 128\): \((128, 32, 32) = 131\,072\) numbers. Fewer pixels, but more detectors per pixel. Coarse levels describe large-scale structure with many features per position.

What is a 3×3 convolution?

A Conv 3×3 layer makes each output channel from a weighted sum over a 3×3 pixel window, summed over all input channels, plus a bias. The same weights are used at every pixel. So the detector slides over the map. The weights are learned. A 1×1 convolution is the same with a 1×1 window: a per-pixel linear map that only changes the channel count.

Show the math

Input \(x\in\mathbb R^{C_{\rm in}\times H\times W}\), output \(y\in\mathbb R^{C_{\rm out}\times H\times W}\). For output channel \(c'\) and pixel \(i\):

$$y_{c',i}=b_{c'}+\sum_{c=1}^{C_{\rm in}}\ \sum_{\delta\in\{-1,0,1\}^2} K_{c',c,\delta}\;x_{c,\,i+\delta}$$

Learned parameters: the kernel \(K\) and bias \(b\): \(9\,C_{\rm in}C_{\rm out}+C_{\rm out}\) numbers. Examples: \(1\to32\): 320. \(32\to32\): 9 248. \(128\to128\): 147 584. The border uses zero padding, so \(H\) and \(W\) do not change.

What does "the 32×32 level" mean?

The 32×32 level is not a small piece of the map. It is the whole map, zoomed out. The map was downsampled twice (128 → 64 → 32). So each of the \(32\times32 = 1\,024\) positions covers a \(4\times4\) patch of the original 128×128 map. At this level the network sees the large-scale layout: where the big clusters, filaments and voids are. The fine detail inside each 4×4 patch is not there any more. It comes back through the skips (Section 8).

Why this level is special on this page:

  • Attention happens only here. Attention compares every position with every other one. Its cost grows with the square of the number of positions: \(1\,024^2 \approx 1.0\) million pairs at 32×32, but \(16\,384^2 \approx 268\) million at 128×128. That is 256 times more. Section 7.
  • In the baseline, the cosmology also enters only here. The 64×64 and 128×128 levels, where small-scale detail is drawn, never see it directly. The new runs temb and tembss change that. Section 4.

3. A ResBlock

ResBlock is short for residual block. It is the basic unit of the network. Every model on this page has 17 of them. A ResBlock takes a tensor \((C_{\rm in}, H, W)\) and returns \((C, H, W)\). The pixel size does not change. Only the channel count may change.

The steps, top to bottom:

  1. GroupNorm (GN) re-centers and re-scales the features. Section 6 explains it.
  2. SiLU is a smooth nonlinear function: \(\mathrm{SiLU}(x)=x\,\sigma(x)=x/(1+e^{-x})\). Without nonlinear steps, a stack of convolutions would be one big linear map.
  3. Conv 3×3 changes the channel count from \(C_{\rm in}\) to \(C\).
  4. Injection (orange). The noise level, and in temb/tembss also the cosmology, enter here as one or two numbers per channel. This is the subject of Section 4. The two orange boxes are the two possible places. A given model uses one of them.
  5. GN, SiLU, Conv 3×3 again.
  6. Add the input back: \(\text{out} = S(x) + h\). This is the residual connection. The block only has to learn a correction to its input, which makes deep networks easy to train. \(S\) is the identity when \(C_{\rm in}=C\). Otherwise it is a 1×1 convolution that changes the channel count.

Dropout is 0 in all our runs, so there is no random masking of features.

Show the math

Block \(b\) receives the conditioning vector \(e\in\mathbb R^{128}\) (Section 4) and has its own learned matrix \(W_b\) and bias \(\mathbf b_b\).

baseline and temb ("default" mode in diffusers): the per-channel number is added before the second GroupNorm.

$$\begin{aligned} h &= \mathrm{Conv}_{3\times3}\big(\mathrm{SiLU}(\mathrm{GN}(x))\big)\\ p &= W_b\,\mathrm{SiLU}(e)+\mathbf b_b\ \in\mathbb R^{C},\qquad W_b\in\mathbb R^{C\times128}\\ h_{c,i} &\leftarrow h_{c,i} + p_c\qquad\text{(same }p_c\text{ at every pixel }i\text{)}\\ h &\leftarrow \mathrm{Conv}_{3\times3}\big(\mathrm{SiLU}(\mathrm{GN}(h))\big)\\ \text{out} &= S(x) + h \end{aligned}$$

tembss ("scale_shift" mode): two numbers per channel, applied after the second GroupNorm.

$$\begin{aligned} h &= \mathrm{Conv}_{3\times3}\big(\mathrm{SiLU}(\mathrm{GN}(x))\big)\\ [\,g,\ \beta\,] &= W_b\,\mathrm{SiLU}(e)+\mathbf b_b\ \in\mathbb R^{2C},\qquad W_b\in\mathbb R^{2C\times128}\\ h_{c,i} &\leftarrow \mathrm{GN}(h)_{c,i}\,(1+g_c) + \beta_c\\ h &\leftarrow \mathrm{Conv}_{3\times3}\big(\mathrm{SiLU}(h)\big)\\ \text{out} &= S(x) + h \end{aligned}$$

In the baseline, \(e=t_{\rm emb}\) carries the noise level only. In temb and tembss, \(e=t_{\rm emb}+c_{\rm emb}\) also carries the cosmology.

4. The key idea: how the cosmology gets in

In temb and tembss, the cosmology reaches the features in three steps: A, B, C below. The baseline uses a different route (cross-attention). The toggle after the steps compares all three.

Step A: build one vector \(e\) per map per step

Some words first. An embedding is a vector of numbers that stands for an input. A Linear layer computes \(y = Wx + b\), where the matrix \(W\) and vector \(b\) are learned. An MLP is two Linear layers with a SiLU between them. z-scored means: subtract the training-set mean, then divide by the training-set standard deviation.

  • Noise level. A fixed sin/cos formula turns the integer \(t\) into 32 numbers \(\gamma(t)\). Then \(\mathrm{MLP}_t\) (32 → 128 → 128) turns them into \(t_{\rm emb}\in\mathbb R^{128}\).
  • Cosmology. \(\tilde\theta\) = the z-scored pair \((\Omega_m,\sigma_8)\), 2 numbers. Then \(\mathrm{MLP}_\theta\) (2 → 128 → 128) turns them into \(c_{\rm emb}\in\mathbb R^{128}\).
  • Sum. \(e = t_{\rm emb} + c_{\rm emb}\). In the baseline, \(e = t_{\rm emb}\) only.

\(e\) is computed once per map per denoising step. The same \(e\) goes to all 17 ResBlocks. It changes when the noise level changes or when the cosmology changes.

Worked example. Suppose the training set has mean \(\Omega_m = 0.30\) with standard deviation 0.05 (illustrative numbers). A request for \(\Omega_m = 0.35\) gives \(\tilde\theta_1 = (0.35-0.30)/0.05 = 1.0\). The z-score puts both cosmology numbers on the same scale, around \(-2\) to \(+2\), which keeps the MLP well behaved.

Step B: each ResBlock turns \(e\) into per-channel numbers

ResBlock \(b\) has its own learned matrix \(W_b\) and bias \(\mathbf b_b\). It computes \(p = W_b\,\mathrm{SiLU}(e) + \mathbf b_b\). In temb, \(p\) has \(C\) numbers: one shift per channel. In tembss, it has \(2C\) numbers: one scale \(g_c\) and one shift \(\beta_c\) per channel. Row \(c\) of \(W_b\) decides how channel \(c\) of this block reacts to the noise level and the cosmology. 17 blocks give 17 different matrices, all fed the same \(e\).

Step C: apply the same number at every pixel of a channel

This is the part that often looks strange. Why add the same number at all 16 384 pixels? Because the cosmology is one property of the whole map. It has no position. The network still has to decide where filaments and voids go. That information comes from the noisy map \(x_t\), through the convolutions. The per-channel number only says how strongly each detector should respond for this cosmology at this noise level. In code this is called broadcasting: a vector of \(C\) numbers is stretched to shape \((C, H, W)\) before the addition.

Worked example. First ResBlock at 128×128, \(C = 32\). \(e\) has 128 numbers. \(W_b\) is \(32\times128\). \(p\) has 32 numbers. Suppose \(p_3 = 0.4\). Then 0.4 is added to all 16 384 pixels of channel 3, and nothing is added to channel 4 unless \(p_4\ne0\). If channel 3 is a "dense filament" detector, the cosmology can make it more or less active. For a clumpy universe (high \(\sigma_8\)) the MLP may learn to give it a larger value. Training decides.

temb versus tembss

The two new models share the same wiring. The difference is where and how the per-channel numbers act inside each ResBlock (see the two orange boxes in Section 3):

  • temb: add \(p_c\) to channel \(c\), before the second GroupNorm.
  • tembss: multiply channel \(c\) by \(1+g_c\) and add \(\beta_c\), after the second GroupNorm.

Section 6 shows why "after GroupNorm" and "multiply" matter.

The baseline route

The baseline does not add the cosmology to \(e\). Instead, a single Linear layer \(W_p\) (2 → 32) turns \(\tilde\theta\) into one token \(u\): a vector of 32 numbers. This token is the only input to the cross-attention layers. There are 6 of them, all at 32×32 (2 down, 1 middle, 3 up). Section 7 shows what they do: each one adds the same fixed vector \(W_O W_V W_p\tilde\theta\) at every position. This vector does not depend on \(t\). The 64×64 and 128×128 blocks never see the cosmology directly. Note that the baseline ResBlocks still get the noise level through \(e = t_{\rm emb}\), by the same "add \(p_c\)" rule as temb.

Show the math

Noise-level code (fixed, no learned numbers). 16 frequencies from fast (\(\omega_0 = 1\)) to slow (\(\omega_{15} = 10000^{-15/16}\approx 1.8\times10^{-4}\)):

$$\gamma(t)=\big[\cos(\omega_k t),\ \sin(\omega_k t)\big]_{k=0}^{15}\in\mathbb R^{32},\qquad \omega_k=10000^{-k/16}$$

The fast components tell neighboring \(t\) apart. The slow ones change smoothly over the whole range 0 to 499. The MLP can read both.

Time embedding (learned):

$$t_{\rm emb}=W^t_2\,\mathrm{SiLU}\!\left(W^t_1\gamma(t)+b^t_1\right)+b^t_2,\qquad W^t_1\in\mathbb R^{128\times32},\ W^t_2\in\mathbb R^{128\times128}$$

Cosmology embedding (learned; temb and tembss only):

$$\tilde\theta=\left(\frac{\Omega_m-\mu_{\Omega}}{s_{\Omega}},\ \frac{\sigma_8-\mu_{\sigma}}{s_{\sigma}}\right),\qquad c_{\rm emb}=W^\theta_2\,\mathrm{SiLU}\!\left(W^\theta_1\tilde\theta+b^\theta_1\right)+b^\theta_2,\qquad W^\theta_1\in\mathbb R^{128\times2}$$

\(\mu,s\) are the training-set means and standard deviations (fixed constants).

$$\boxed{\,e = t_{\rm emb} + c_{\rm emb}\ \ (\text{temb, tembss}),\qquad e = t_{\rm emb}\ \ (\text{baseline})\,}$$

Per-block numbers (learned \(W_b, \mathbf b_b\) for each of the 17 blocks):

$$p^{(b)} = W_b\,\mathrm{SiLU}(e)+\mathbf b_b,\qquad W_b\in\mathbb R^{C\times128}\ (\text{temb}),\quad W_b\in\mathbb R^{2C\times128}\ (\text{tembss})$$

Baseline token: \(u = W_p\tilde\theta\in\mathbb R^{32}\), with \(W_p\in\mathbb R^{32\times2}\) learned. It has shape \((B, 1, 32)\): one token per map.

Key point: the cosmology itself is never a parameter. It is an input. The learned parts are the matrices that decide how each channel of each block reacts to it.

6. Shift or scale? And what GroupNorm does

GroupNorm in words

GroupNorm (GN) splits the \(C\) channels into 32 groups. For one map and one group, it computes the mean and the variance over the group's channels and all pixels. It subtracts the mean and divides by the standard deviation. Then it multiplies channel \(c\) by a learned \(a_c\) and adds a learned \(d_c\). These two numbers do not depend on the cosmology.

Group sizes in our network: at \(C = 32\), one channel per group. At \(C = 64\), two. At \(C = 128\), four.

Worked example (one channel, 4 pixels). Values \([2, 4, 6, 8]\). Mean 5, variance 5, standard deviation 2.24. After normalization: \([-1.34, -0.45, 0.45, 1.34]\). Now multiply the input by 10: \([20, 40, 60, 80]\). Mean 50, standard deviation 22.4. After normalization: the same \([-1.34, -0.45, 0.45, 1.34]\). Add 100 to every value instead: again the same result. GN erases the overall amplitude and the overall level of a group.

Why this matters here: after GN, a clumpy universe and a smooth universe give features with the same spread. Something that knows the cosmology must put the amplitude back. In tembss the next step multiplies by \(1+g_c(\tilde\theta,t)\). So the cosmology sets the amplitude of every channel, in every block. In temb the block only adds \(p_c\). An added constant moves the mean of a channel. It does not change the contrast between pixels.

Try it: shift versus scale

One channel, two pixels, after GN: a filament pixel at +1.0 and a void pixel at −1.0. Contrast = 2.0. Move the sliders.

What to notice:

  • The shift moves both bars together. The difference between filament and void stays 2.0. A shift cannot make the map more or less clumpy on its own.
  • The scale stretches the bars apart or pushes them together. With \(g_c = 1\) the contrast doubles. With \(g_c = -0.8\) it shrinks to 0.4.
  • In tembss, every channel of every block has its own \(g_c\) and \(\beta_c\), and both depend on the cosmology and on \(t\).

Caveat: the shift is not useless. The SiLU and the next convolution are nonlinear, so a shift can still change what later layers do. But only the scale acts on the contrast directly.

Show the math

GroupNorm with 32 groups. Let \(g(c)\) be the group of channel \(c\), and \(\mu_{g}, \sigma_g^2\) the mean and variance over all channels in that group and all pixels of one map:

$$\mathrm{GN}(h)_{c,i}=a_c\,\frac{h_{c,i}-\mu_{g(c)}}{\sqrt{\sigma_{g(c)}^2+\epsilon}}+d_c$$

\(a_c, d_c\) are learned, cosmology-independent. In tembss the block then forms \(\tilde h_{c,i} = (1+g_c)\,\mathrm{GN}(h)_{c,i}+\beta_c\). Multiplying by a constant multiplies the spread over pixels:

$$\mathrm{Std}_i\big[\tilde h_{c,i}\big] = |1+g_c(\tilde\theta,t)|\ \mathrm{Std}_i\big[\mathrm{GN}(h)_{c,i}\big]$$

In temb the block forms \(\mathrm{GN}(h+p)\) instead. Adding a constant per channel changes the means but not the within-channel spread.

A subtle consequence (verified numerically: changing \(e\) changes a C = 32 temb block's output by about 5×10⁻⁷, i.e. not at all). In temb and in the baseline, \(p_c\) is added before the second GroupNorm. At \(C=32\) each group is a single channel, so GN subtracts the channel mean, which now includes \(p_c\):

$$\mathrm{GN}(h_c+p_c) = a_c\,\frac{(h_{c,i}+p_c)-(\mu_c+p_c)}{\sqrt{\sigma_c^2+\epsilon}}+d_c=\mathrm{GN}(h_c)$$

So in the five 128×128 ResBlocks, the added \(p_c\) is cancelled exactly, for the cosmology (temb) and for the noise level (temb and baseline). At \(C=64\) (two channels per group) only the difference between the two shifts in a group survives. At \(C=128\) (four per group) most of the shift survives. tembss applies its numbers after GN, so nothing is cancelled at any level.

7. Attention: self versus cross

At the 32×32 level the feature tensor is \((128, 32, 32)\). For attention it is viewed as 1 024 tokens, one per position. A token is one vector: here, the 128 channel values at one position. Attention lets each position look at all other positions of the same map. A convolution only sees its 3×3 neighbors.

Self-attention: one position looks at all 1 024 positions

For every position \(i\) the layer builds three vectors from its 128 channels with learned matrices: a query \(q_i = W_Q h_i\), a key \(k_i = W_K h_i\) and a value \(v_i = W_V h_i\).

  1. Compare the query of \(i\) with the key of every \(j\): the dot product \(q_i\cdot k_j\). Large means "relevant".
  2. Turn the 1 024 scores into weights \(A_{ij}\) with a softmax: \(A_{ij}=e^{s_{ij}}/\sum_j e^{s_{ij}}\). The weights are positive and sum to 1.
  3. Output for \(i\) = \(\sum_j A_{ij} v_j\), then one more learned matrix \(W_O\).

Two different kinds of mixing happen here. Keep them apart:

  • Channels are mixed by the matrices \(W_Q, W_K, W_V, W_O\). Each output channel is a learned combination of all 128 input channels at the same position. Channels do not "attend" to each other.
  • Positions are mixed by the weights \(A\). \(A\) is a \(1\,024\times1\,024\) matrix: one row per query position, one column per key position.

Multi-head: 16 small attentions side by side

In practice the 128 channels are split into 16 heads of 8 channels each. Every head has its own small \(W_Q, W_K, W_V\) (128 → 8) and its own \(1\,024\times1\,024\) weight matrix \(A\). So one head can look at "nearby filaments" while another looks at "the largest void". The 16 outputs (8 channels each) are concatenated back to 128 channels and mixed by \(W_O\).

The batch: every map attends only to itself

During training the network sees \(B = 32\) maps at once. Attention is computed separately for each map. A position in map 1 never attends to a position in map 2. Each map has its own \(A\). In the baseline, each map also attends only to its own cosmology token. The shapes make this visible: the batch index \(B\) is carried along and never mixed.

Shapes at one self-attention layer (training, B = 32): features \(h\): \((32, 1024, 128)\). \(Q, K, V\): \((32, 16, 1024, 8)\), that is (batch, heads, positions, channels per head). Weights \(A\): \((32, 16, 1024, 1024)\). Output: \((32, 1024, 128)\), then reshaped back to \((32, 128, 32, 32)\).

Cross-attention with one token (baseline only)

Cross-attention is attention where the queries come from the map but the keys and values come from somewhere else. In the baseline they come from the cosmology token \(u = W_p\tilde\theta\) (32 numbers). There is only one token. So each query has exactly one key to compare with. \(A\) is \(1\,024\times1\). A softmax over a single number is always 1: \(e^{s}/e^{s} = 1\).

The result: every position receives the same vector \(W_O W_V u = W_O W_V W_p\tilde\theta\). It does not depend on the position. It does not depend on \(t\). It does not depend on the map. The six cross-attention layers each add one fixed, cosmology-dependent vector at every position of the 32×32 level, and nothing anywhere else.

Worked example. Query \(q_i\) of position 17 gives score \(s = q_{17}\cdot k_u/\sqrt d = 2.3\). The softmax over the single score is \(e^{2.3}/e^{2.3} = 1\). Position 900 gives \(s = -4.1\). Its weight is \(e^{-4.1}/e^{-4.1} = 1\) as well. The value of the score never matters.
Show the math

Self-attention at 32×32. Write the features as a matrix \(h\in\mathbb R^{1024\times128}\) (one row per position). Per head, with \(d = 8\):

$$Q = hW_Q,\quad K = hW_K,\quad V = hW_V\qquad (W_Q,W_K,W_V\in\mathbb R^{128\times8})$$ $$A=\mathrm{softmax}_{\rm rows}\!\left(\frac{QK^\top}{\sqrt d}\right)\in\mathbb R^{1024\times1024},\qquad \text{head output}=AV\in\mathbb R^{1024\times8}$$ $$\mathrm{out}=\big[\,A^{(1)}V^{(1)}\ \big|\ \cdots\ \big|\ A^{(16)}V^{(16)}\,\big]\,W_O\in\mathbb R^{1024\times128}$$

Each row of \(A\) sums to 1. Row \(i\) says how much position \(i\) uses each position \(j\). With a batch, every tensor gets a leading \(B\) index and the products are done per map.

Cross-attention (baseline). The keys and values come from the single token \(u = W_p\tilde\theta\in\mathbb R^{32}\):

$$K = uW_K\in\mathbb R^{1\times d},\qquad V = uW_V\in\mathbb R^{1\times d},\qquad A=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt d}\right)\in\mathbb R^{1024\times1}=\mathbf 1$$ $$\mathrm{out}_i = W_O W_V W_p\,\tilde\theta\qquad\text{for every position } i$$

In the baseline each 32×32 attention block is a transformer block: self-attention, then cross-attention, then a feed-forward layer. In temb and tembss the attention is self-attention only.

Cost. \(A\) has (positions)² entries per head. At 32×32: \(1\,024^2\approx1.0\times10^6\). At 128×128 it would be \(16\,384^2\approx2.7\times10^8\), 256 times more, per head and per map. That is why attention is used only at the coarsest level.

8. Skip connections

Problem: at 32×32 the fine detail is gone (Section 2). The up path has to draw it again. A skip connection helps: it hands the up path a copy of the down-path features at the same resolution. The copy still has the fine detail.

How the copy is joined: by concatenation along the channel axis. The up-path tensor is a stack of \(C_{\rm up}\) images. The skip is a stack of \(C_{\rm skip}\) images of the same size. Put the two stacks on top of each other: \(C_{\rm up}+C_{\rm skip}\) images. The ResBlock then maps this back to \(C\) channels. That is why the up path has 3 ResBlocks per level and the down path only 2: each up ResBlock consumes one skip, and there are 9 skips.

9. Training: the loss and the min-SNR weight

Training teaches the network to undo noise. One training step:

  1. Take a clean map \(x_0\) and its cosmology \(\tilde\theta\).
  2. Pick a random noise level \(t\) and random Gaussian noise \(\varepsilon\). Mix them: \(x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\varepsilon\). Here \(\bar\alpha_t\) is a fixed number between 0 and 1 from the noise schedule (squaredcos_cap_v2). Near 1 at \(t = 0\) (almost clean), near 0 at \(t = 499\) (almost pure noise).
  3. The network predicts \(\hat v\). The target is \(v = \sqrt{\bar\alpha_t}\,\varepsilon-\sqrt{1-\bar\alpha_t}\,x_0\). This v-prediction target is a mix of "the noise" and "minus the signal". It is well behaved at both ends of the schedule.
  4. Loss = weighted mean squared error, \(w_t\,\|\hat v - v\|^2\), averaged over the batch. Update all learned parameters.

The signal-to-noise ratio is \(\mathrm{SNR}_t = \bar\alpha_t/(1-\bar\alpha_t)\). It is large for nearly clean maps and small for very noisy ones. The min-SNR weight is

$$w_t=\frac{\min(\mathrm{SNR}_t,\,5)}{\mathrm{SNR}_t+1}$$

It caps the influence of the nearly-clean steps (large SNR), where the task is easy and the gradients would otherwise dominate. tembss_nosnr uses \(w_t = 1\) for every step.

Worked example. \(\mathrm{SNR}=0.1\) (very noisy): \(w = 0.1/1.1 = 0.09\). \(\mathrm{SNR}=1\): \(w = 1/2 = 0.5\). \(\mathrm{SNR}=5\): \(w = 5/6 = 0.83\) (the peak). \(\mathrm{SNR}=100\) (almost clean): \(w = 5/101 = 0.05\).

Why we expect this to matter (hypothesis, to be tested). In the baseline, the label reaches only the 32×32 level, as a fixed shift that does not depend on the noise level. The 64×64 and 128×128 blocks and the high-resolution skips never see it. At small \(N\), the baseline's generated maps are too smooth: they have too little small-scale power (\(P(k)\) ratio about 0.82) and \(\Omega_m\) reads biased low. tembss gives every block an adjustment that depends on both the cosmology and the noise level. temb does too, except at 128×128, where GroupNorm cancels its shift exactly. tembss can also set each channel's amplitude after GroupNorm, which is a direct handle on clustering strength.

Key points

  • The input map is never changed by the cosmology. The cosmology acts on the network's internal features, channel by channel.
  • In temb and tembss, one vector \(e\) (noise level + cosmology) feeds all 17 ResBlocks. Each block has its own learned matrix that turns \(e\) into one number per channel (temb) or two (tembss).
  • The same number is used at every pixel of a channel because the cosmology is a global property. Where structure goes comes from the noisy map; how strongly each detector responds comes from \(e\).
  • GroupNorm erases each group's amplitude. Only the tembss scale puts a cosmology-dependent amplitude back.
  • Cross-attention to one token is a fixed shift: the softmax weight is always 1. In the baseline this is the only entry point, and it is at 32×32 only.
  • Attention mixes positions (through \(A\)) and channels (through the \(W\) matrices) within one map. Maps in a batch never see each other.
