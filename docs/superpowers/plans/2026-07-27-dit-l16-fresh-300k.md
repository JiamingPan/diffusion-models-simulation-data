# Fresh DiT-L16 300k Sweep Implementation Plan

> **Required subskill:** Use `superpowers:test-driven-development` for each
> implementation task and `superpowers:verification-before-completion` before
> the final commit or push.

**Goal:** Build a reproducible, isolated sweep that trains ten fresh DiT-L16
models from initialization through 300,000 requested optimizer updates, samples
the 200k, 225k, 250k, 275k, and 300k checkpoints, runs PCA and SSCD
nearest-neighbor analyses, and updates the results notebook without presenting
an incomplete or unequal-budget curve as a clean scaling result.

**Architecture:** A frozen manifest records all ten dataset sizes and twelve
sequential 25k-update stages. Stage 1 starts from a deterministic fresh
initialization. Later stages resume the exact previous scientific checkpoint
with model, optimizer, learning-rate scheduler, noise scheduler, and RNG state
restored. Scientific sampling and analysis occur after stages 8 through 12.
All checkpoints, samples, tables, and logs use fresh sweep-specific roots.

**Tech Stack:** Python 3.10, PyTorch, diffusers
`DiTTransformer2DModel`, cosmo_diffusion, Slurm, NumPy, pandas, matplotlib,
Jupyter, PCA, SSCD, unittest/pytest.

**Global Constraints:**

- Train all ten dataset sizes `2^6` through `2^15` from initialization to
  300k requested optimizer updates.
- Use one GPU per task and at most two concurrent GPU tasks.
- Use seed 123 for initialization, data order, diffusion-noise draws, and
  sampling.
- Do not read from or write to the historical
  `nf_generalize_fig2_dit_l16_continue` checkpoint tree.
- Keep the DiT-L16 architecture and training hyperparameters fixed across all
  ten runs.
- Save recovery checkpoints approximately every 5k updates.
- Preserve scientific checkpoints at 200k, 225k, 250k, 275k, and 300k.
- Never delete checkpoints automatically.
- Refuse to publish a full-range curve when any expected dataset-size result is
  missing.
- Treat the 200k L8/L12/L16 comparison as the primary equal-budget capacity
  diagnostic. Label any plot containing L16 at 300k and L8/L12 at 200k as an
  unequal-update final-outcome comparison.
- Do not tune or rerun until L16 appears to the right of L12. Report the
  measured result.
