## What the figures show

1. (a) Real maps: **each bar uses 128 maps per cosmology**, all 128 slices of one 128³ box (adjacent, correlated). Median bias −0.0004; 27/32 covered at 68%, 32/32 at 95%; R² of the medians about the 1:1 line 0.90, fitted slope 0.80 [S]. 2. (b, c) Generated maps, 64 per cosmology [S]: N = 64 bias −0.048 (−0.52 W), 9/32 at 68%, 12/32 at 95%; N = 256 −0.034 (−0.37 W), 13/32, 18/32; N = 32768 +0.005 (+0.05 W), 21/32, 30/32. Real maps: 27/32 and 32/32.
3. Near/far, recomputed against each N's own training subset (64, 256, and 968 cosmologies for N = 32768) [NF]. N = 64: near bias −0.012, 8/16 covered at 68%; far −0.057, 1/16. N = 256: near −0.014, 8/16; far −0.057, 5/16. N = 32768: near +0.018, 11/16; far −0.002, 10/16.
4. At N = 64 far cosmologies are covered less (1/16 against 8/16); real maps with the same split are unaffected (13–14/16 in every group, bias −0.013 to +0.004) [NF]. At N = 256 the gap is smaller (5/16 against 8/16); with 16 per group no significance test is in a result file. Far cosmologies also have higher median true Ωm [PC], where the generated bias is larger, so distance and Ωm are not yet separated. At N = 32768 the median nearest-training distance is 0.009 (near) against 0.020 (far) [NF].
5. (d) Map-to-map spread at fixed cosmology, median 16–84% half-width [S]: real 0.047, N = 64 0.019, N = 256 0.026, N = 32768 0.041. Thinning real maps to 64 slices per box gives 0.046 and 25/32 [S], so the gap is not an artefact of 64 against 128 maps. This is slice-to-slice spread inside one box, not box-to-box cosmic variance.
