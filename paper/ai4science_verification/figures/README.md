# Figure staging

Place final, source-traceable manuscript figures in this directory. Prefer PDF
for vector plots and PNG only for raster field images.

Each figure should have a note in the analysis notebook or manuscript source
recording:

- the input table or sample files;
- architecture, training-set size, checkpoint, and sampler;
- number of generated samples and random seeds;
- definition of every plotted statistic and uncertainty interval;
- the script or notebook cell that produced the file.

Do not place preliminary figures in the main paper without labels that make
unequal training budgets or incomplete controls explicit.

## U-Net-128 nearest-training audit

`nearest_training_u128.pdf` and `nearest_training_u128.csv` are generated by
`scripts/plot_nf_conditional_bias_paper_figures.py`, also invoked from the
paper-export section of `notebooks/nf_conditional_bias_vgg_results.ipynb`.
The figure uses generated sample index 0 for each $N_{2D}=2^6,\ldots,2^{11}$
run, searches the complete configured training subset for its closest slice,
and plots $P_{\rm gen}(k)/P_{\rm real}(k)$ only through the $128\times128$
Nyquist limit $k=64$. The CSV records the exact config path, similarity,
power-spectrum error, normalized SSCD Fr\'echet diagnostic, and equal sample
counts used for the generated-to-real and real-to-real distances.
