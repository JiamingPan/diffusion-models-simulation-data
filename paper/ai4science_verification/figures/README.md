# Figure staging

Place final, source-traceable manuscript figures in this directory. Prefer PDF
for vector plots and PNG only for raster field images.

Each figure should have a note in the analysis notebook or manuscript source
recording:

- the input table or sample files;
- architecture, training-set size, checkpoint, and sampler;
- number of generated samples and random seeds;
- definition of every plotted statistic and uncertainty interval;
- the script or notebook cell that produced the file.

Do not place preliminary figures in the main paper without labels that make
unequal training budgets or incomplete controls explicit.
